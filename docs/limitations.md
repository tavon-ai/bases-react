# Limitations

This alpha targets a Bases-compatible subset, not complete Obsidian parity.

Deferred features include:

- Card image/cover polish.
- Advanced toolbar actions and multi-filter editing.
- Inline editing and persistence callbacks.
- Map rendering.
- Obsidian vault/plugin bridge.
- Exhaustive compatibility fixtures for every Obsidian Bases syntax edge case.

See `deferred-features.md` for the current later-feature list.
