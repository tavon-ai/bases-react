# @bases-react/react

React components for rendering evaluated Bases views.

## APIs

- `<BaseView base={base} files={files} view="Projects" />`
- `<BaseTable result={result} />`
- `<BaseList result={result} />`
- `<BaseCards result={result} />`
- `<BaseProvider renderers={...}>`

Import styles once:

```ts
import '@bases-react/react/styles.css'
```
