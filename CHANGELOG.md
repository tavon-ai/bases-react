# Changelog

## 0.1.0-alpha.0

Initial alpha preparation for the standalone Obsidian Bases React package suite.

- Core `.base` parsing, normalization, filters, formulas, summaries, and evaluation.
- React table, list, and cards shells with toolbar controls.
- TanStack Table adapter.
- Filesystem Markdown/frontmatter adapter.
- Vite demo using local Markdown data.
