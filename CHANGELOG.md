# Changelog

## 0.1.0-alpha.2

- Fix Markdown frontmatter parsing in `@bases-react/fs` so duplicate YAML keys and malformed frontmatter do not crash consumers.
- Fix published `@bases-react/fs` dependency metadata for package manager installs.

## 0.1.0-alpha.1

- Superseded by `0.1.0-alpha.2` due to invalid published dependency metadata.

## 0.1.0-alpha.0

Initial alpha preparation for the standalone Obsidian Bases React package suite.

- Core `.base` parsing, normalization, filters, formulas, summaries, and evaluation.
- React table, list, and cards shells with toolbar controls.
- TanStack Table adapter.
- Filesystem Markdown/frontmatter adapter.
- Vite demo using local Markdown data.
